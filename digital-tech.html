《數位科技概論》第二週教學講義與活動總覽

本週課程包含 9 個核心學習活動，涵蓋 GitHub 操作、HTML 結構化與 CSS 網頁佈局設計。

活動學習主題明細

活動主題 核心檔案 學習重點與技巧
01：把小站變成我的（水與生活） 01-html-11517007.html HTML 文字層級 (`<h1>`–`<h3>`) 與標籤屬性 (`<b>`, `<i>`, `<sub>`, `<sup>`)
02：讓小站有聲有影（校園自然觀察） 02-html-media-11517007.html 多媒體元素 (`<img>`, `<audio>`, `<video>`) 與圖片 `alt` 設定
03：整理我的學習計畫（紙橋挑戰社） 03-html-plan-11517007.html 清單 (`<ul>`/`<ol>`) 與表格結構 (`<table>`, `<tr>`, `<td>`)
04：設計一張活動報名表 04-html-form.html 表單元件 (`<input>`, `<select>`, `<textarea>`) 與 `label` 關聯
05：換一種風格 05-css-style.html CSS 色彩、Box Model 內外距 (`padding`/`margin`) 設定
06：網頁版型佈局 06-css-layout.html 網頁多欄位佈局與 CSS Grid 基本應用
07：把內容排得整齊 07-css-cards.html Flexbox 卡片排列與 `object-fit` 圖片裁切
08：從電腦版變成手機版 08-css-rwd.html 響應式網頁設計 (RWD) 與 `@media` 媒體查詢
09：修正無障礙機檢 09-css-accessibility.html WAVE 無障礙檢測、高色彩對比度與 `:focus-visible` 鍵盤焦點

📁 作業 03：紙橋挑戰社：活動準備頁（點擊展開/收合）

紙橋挑戰社：活動準備頁

我們要用簡單的材料，設計一座能承重的紙橋。

要帶的材料

  • A4 紙 3 張
  • 膠帶 1 卷
  • 積木 10 個

挑戰步驟

  1. 先畫出紙橋草圖
  2. 再折出橋面並固定
  3. 逐一放上積木，觀察能承受的重量
  4. 記錄結果，討論如何改進
