《數位科技概論》第二週教學講義與活動總覽

本週課程包含 9 個核心學習活動，涵蓋 GitHub 操作、HTML 結構化與 CSS 網頁佈局設計[cite: 1]。

活動學習主題明細

活動主題 核心檔案 學習重點與技巧
01：把小站變成我的 01-html-text.html HTML 文字層級 (`<h1>`–`<h3>`) 與標籤屬性 (`<b>`, `<i>`)[cite: 1]
02：讓小站有聲有影 02-html-media.html 多媒體元素 (`<img>`, `<audio>`, `<video>`) 與圖片 `alt` 設定[cite: 1]
03：整理我的學習計畫 03-html-plan.html 清單 (`<ul>`/`<ol>`) 與表格結構 (`<table>`, `<tr>`, `<td>`)[cite: 1]
04：設計一張活動報名表 04-html-form.html 表單元件 (`<input>`, `<select>`, `<textarea>`) 與 `label` 關聯[cite: 1]
05：換一種風格 05-css-style.html CSS 色彩、Box Model 內外距 (`padding`/`margin`) 設定[cite: 1]
06：網頁版型佈局 06-css-layout.html 網頁多欄位佈局與 CSS Grid 基本應用[cite: 1]
07：把內容排得整齊 07-css-cards.html Flexbox 卡片排列與 `object-fit` 圖片裁切[cite: 1]
08：從電腦版變成手機版 08-css-rwd.html 響應式網頁設計 (RWD) 與 `@media` 媒體查詢[cite: 1]
09：修正無障礙機檢 09-css-accessibility.html WAVE 無障礙檢測、高色彩對比度與 `:focus-visible` 鍵盤焦點[cite: 1]

作業打包與繳交規範

  • HTML 單獨作業 (01, 03, 04)：繳交單一 HTML 檔 (`0X-html-xxx-學號.html`)[cite: 1]。
  • 多媒體作業 (02)：需連同 media-02 資料夾打包為 ZIP (`02-html-media-學號.zip`)[cite: 1]。
  • CSS 作業 (05–09)：挑選其中 1 個案例修改，打包為 CSS-活動編號-學號.zip[cite: 1]。
